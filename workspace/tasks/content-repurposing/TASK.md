# Task: content repurposing

GOAL: Turn one long piece of writing into a week of posts and a short video script,
using only what the source says.

INPUTS:
- `sample_blog_post.md` (in this folder). It can be any blog post, talk transcript, or
  voice-memo text; swap in your own.

DONE MEANS:
- `output/linkedin.md`: one LinkedIn post, 120 to 220 words, with a first line that
  stands on its own.
- `output/short-posts.md`: three short posts, each under 280 characters, each built on a
  different point from the source.
- `output/newsletter.md`: one newsletter paragraph, 80 to 120 words.
- `output/video-script.md`: a 60-second video script (130 to 160 spoken words) with a
  hook, three beats, and a closing line, plus a one-line note on what to show on screen
  for each beat.
- `output/claims-check.md`: a table of every factual claim used in the outputs (numbers,
  dates, results) with the exact source sentence that supports it.

LIMITS:
- Every claim comes from the source. No new numbers, results, or promises.
- Write in the owner's voice as described in preferences.md.
- Drafts only; nothing is posted.

TIME: a person doing this by hand takes about 90 minutes.
