# Lessons

What the agent has learned while working for you. The reflect step appends an entry after
each run, and every plan reads this file first. Each entry begins with an "Applies when:"
line that describes the situation where the lesson should fire again.

Entry format:

    ## <short title> (<YYYY-MM-DD>)
    Applies when: <the situation, described so a future task can recognize it>
    <what to do, in one to three sentences, and why>
